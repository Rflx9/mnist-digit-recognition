## 🧠 Overview

This project implements an end-to-end deep learning pipeline for **handwritten digit classification** using the classic MNIST dataset. It covers every stage of a real ML project:

1. **Data loading & preprocessing** — normalize images, reshape for CNN input
2. **Model design** — a 3-block CNN with ReLU activations and dropout regularization
3. **Training** — with early stopping, model checkpointing, and LR scheduling
4. **Evaluation** — accuracy scores, classification report, confusion matrix
5. **Deployment** — an interactive Streamlit web app for real-time prediction

This project is designed to be **beginner-friendly** with thorough comments throughout every file, while also demonstrating industry-standard practices suitable for a professional portfolio.

## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/mnist-digit-recognition.git
cd mnist-digit-recognition
```

### 2. Set Up a Virtual Environment (recommended)

```bash
python -m venv venv

# On Windows:
venv\Scripts\activate

# On macOS/Linux:
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the Model

```bash
python train.py
```

This will:
- Download the MNIST dataset automatically (~11 MB)
- Train the CNN for up to 15 epochs (early stopping applies)
- Save the best model as `mnist_cnn_model.keras`
- Save training plots to `plots/`

### 5. Evaluate the Model

```bash
python evaluate.py
```

This will:
- Load the saved model
- Run inference on 10,000 test images
- Print accuracy and per-class classification report
- Save confusion matrix and misclassified examples to `plots/`

### 6. Launch the Web App

```bash
streamlit run app.py
```

Then open your browser to `http://localhost:8501`

## 🔍 How It Works

### Data Pipeline

```
Raw MNIST Images (28×28, uint8, 0–255)
        ↓
Normalize: divide by 255 → float32, range [0.0, 1.0]
        ↓
Reshape: (28, 28) → (28, 28, 1)   # Add channel dimension
        ↓
Split: 54,000 train / 6,000 val / 10,000 test
```

### Training Pipeline

```
Input images → CNN → Softmax probabilities (10 classes)
     ↓
Adam optimizer + Sparse Categorical Crossentropy loss
     ↓
Callbacks: EarlyStopping, ModelCheckpoint, ReduceLROnPlateau
     ↓
Best model saved automatically
```

---

## 🏗️ Model Architecture

```
Input: (28, 28, 1)
│
├─ Conv2D(32, 3×3, relu, same)    ← Detects basic edges & textures
├─ MaxPooling2D(2×2)              ← Halves spatial dimensions
│
├─ Conv2D(64, 3×3, relu, same)    ← Detects curves & shapes
├─ MaxPooling2D(2×2)              ← Halves again
│
├─ Conv2D(64, 3×3, relu, same)    ← Detects digit-level features
│
├─ Flatten                         ← 3D → 1D (for Dense layers)
├─ Dropout(0.5)                   ← Prevents overfitting
├─ Dense(128, relu)               ← Combines all features
│
└─ Dense(10, softmax)             ← Output: probabilities for 0–9
```

**Total parameters:** ~93,000 (lightweight and fast)

## 💻 Usage

### Training Options

```bash
# Default training
python train.py

# The model is saved as 'mnist_cnn_model.keras' automatically
```

### Evaluation Options

```bash
# Evaluate default model
python evaluate.py

# Evaluate a specific model file
python evaluate.py --model path/to/your_model.keras
```

### Web App

```bash
streamlit run app.py
```

**In the web app you can:**
- Upload any image (PNG/JPG/BMP) of a handwritten digit
- View the predicted digit and confidence score
- Inspect the probability distribution across all 10 classes
